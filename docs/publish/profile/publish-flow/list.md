# `appcircle publish profile publish-flow list`

Get list of publish flows of a publish profile.

```plaintext
appcircle publish profile publish-flow list [options]
```

## Options

```plaintext
      --platform <platform>      Platform (ios or android)
      --publishProfileId <uuid>  Publish profile ID
      --publishProfile <string>  Publish profile name (alternative to --publishProfileId)
```

